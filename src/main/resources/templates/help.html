RSS25SB Service - Aide

Accueil

Documentation des API

URL Méthode Description Format
/ GET Page d'accueil du service HTML
/help GET Page d'aide du service HTML
/rss25SB/resume/xml GET Liste résumée des articles (id, date, guid) XML
/rss25SB/resume/html GET Liste résumée des articles au format HTML HTML
/rss25SB/resume/xml/{id} GET Détail d'un article spécifique au format XML XML
/rss25SB/html/{id} GET Détail d'un article spécifique au format HTML HTML
/rss25SB/insert POST Ajout d'un flux RSS25SB (validation XSD) XML
/rss25SB/delete/{id} DELETE Suppression d'un article XML
/rss25SB/search GET Recherche d'articles par date et/ou catégorie
Paramètres: date (yyyy-MM-dd), category (string)		 XML

Exemples d'utilisation

Récupérer tous les articles

GET /rss25SB/resume/xml

Récupérer un article spécifique

GET /rss25SB/resume/xml/1

Ajouter un nouveau flux RSS25SB

POST /rss25SB/insert
Content-Type: application/xml

<rss25SB version="2.5">
    <channel>
        <title>Example Feed</title>
        <link>http://example.org/</link>
        <description>An example feed</description>
        <item>
            <title>Example Item</title>
            <link>http://example.org/item</link>
            <description>Example description</description>
            <pubDate>2025-05-01T12:00:00</pubDate>
            <guid>http://example.org/item/1</guid>
            <category>Example Category</category>
        </item>
    </channel>
</rss25SB>

Supprimer un article

DELETE /rss25SB/delete/1

Rechercher des articles par date

GET /rss25SB/search?date=2025-01-01

Rechercher des articles par catégorie

GET /rss25SB/search?category=Example
